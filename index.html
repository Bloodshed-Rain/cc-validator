BIN lookup · card type detection · Luhn validation · issuer info — all offline

What it does

BIN Lookup
Instantly identify bank, country, card type, and level from first 6 digits
Luhn Check
Validate card number structure — catches typos and generated numbers
Card Type
Visa, Mastercard, Amex, Discover, JCB — auto-detected
Issuer Info
Bank name, country code, card level (Classic/Gold/Platinum/Black)
Offline
No API calls, no logging, no network — runs entirely local
Batch Mode
Paste up to 500 cards at once, export results as CSV
